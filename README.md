# 128-BIT-INTEGERS
A SET OF HEADERS USEFUL TO PERFORM INPUT AND OUTPUT OPERATIONS AND SOME USEFUL MATHEMATICAL FUNCTIONS FOR 128 BIT INTEGERS IN C/C++. FURTHER FUNCTIONALITIES MAY BE ADDED IN THE FUTURE AS NEEDED.


# OBSERVATION:

THE TOOM-COOK 3 AND KARATSUBA MULTIPLICATION ALGORITHMS ARE OF PRACTICAL USE ONLY FOR NUMBERS WAY BIGGER THAN THE VALUES THAT CAN BE STORED ON A 128 BIT INTEGER. THE IMPLEMENTATIONS HERE PROVIDED WERE DONE ONLY FOR PEDAGOGICAL PUPORSES.
